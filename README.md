# Solar System 3D

### Interactive web visualization experiment

**Project under construction**

This repository contains a TypeScript-based web application workspace for an interactive project related to a 3D solar system. It uses Vite-based development tooling and includes additional application and data infrastructure.

## Technology

TypeScript · Vite · React ecosystem · Node.js

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run test
npm run build
```

The current source is a development workspace. Specific visualization features and deployment readiness should be verified from the working application rather than inferred from the repository name.
